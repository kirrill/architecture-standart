**Обоснование решений**

- Использование SFTP сервера для предоставления файлов со ставками сотрудникам партенрского кол-центра
    - Прост и быстр в развертывании
    - Обеспечивает надежное шифрование передаваемых данных

- Использование Kafka для передачи данных по ставкам в систему кол-центра банка
    - Kafka уже развернута на предыдущем этапе, к тому же топик со ставками уже создан, поэтому остается только подписаться на этот топик из системы кол-центра

- Разработка отдельного сервиса получения ставок в системе кол-центра
    - Преемственный подход к разработке системы - система кол-центра уже использует микросервисный подход

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

|**Альтернатива**|**Недостатки, ограничения, риски**|
| :-: | :- |
|Прямой доступ партнёра к API|Невозможен по требованиям безопасности (внешняя система не поддерживает API)|
|Ручная отправка файлов|Риск человеческой ошибки, задержки в актуальности данных|
|Использование email для передачи | Низкая безопасность, риск попадания данных к третьим лицам.|
